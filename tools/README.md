# Offline single-file builder

`roadmap-builder.html` is the original zero-dependency tool this project grew
out of. It still has one job the server does not do yet: exporting a roadmap
as a single self-contained HTML page for Confluence, SharePoint or an airgapped
network. Download a roadmap with **Download JSON (inline images)**, open this
file in a browser, **Import JSON**, then **Export HTML**.
